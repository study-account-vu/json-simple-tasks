#

#     1.1.1 no longer hit NoSuchMethodError.

#     1.1.1; getMessage() returns it too, which 1.1.1 did not do.
#   * ParseException.serialVersionUID is back to -7880698968187728548.
#

#              becoming Serializable. Nothing here removes or narrows anything.
#
#   BEHAVIOUR  arrays and non-List Collections now encode as JSON arrays rather
#              than falling through to Object.toString(); integers that overflow
#              long report ParseException instead of letting a raw
#              NumberFormatException escape.
#
